# solvia LP

ライバー事務所 [solvia](https://solvialp-ten.vercel.app) のランディングページプロジェクト。

## 🚀 知り合いの方へのデプロイ手順

このプロジェクトをあなたのVercelアカウントにデプロイするには、以下のボタンをクリックしてください。

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Ftanakaryotadayo-wq%2Fsolvia_lp)

1. ボタンをクリック
2. Vercelにログイン（またはアカウント作成）
3. プロジェクト名を入力して `Create` をクリック
4. 自動的にビルドとデプロイが完了します

## 開発環境のセットアップ

```bash
npm install
npm run dev
```

<http://localhost:3000> にアクセスして確認できます。
